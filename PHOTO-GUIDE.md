# Faves, My Love — the 38 photograph slots

This experience has **exactly 38 photograph placeholders**. Each one has a unique id from `faves-photo-01` to `faves-photo-38` and can be replaced independently without touching any layout.

## How to add or replace photographs

1. Open the website and click **Photo studio** in the bottom-left corner (camera icon).
2. Choose a slot from the list — the panel shows the exact id, where it appears, and a preview.
3. Click **Choose photograph** (or drop a file onto the preview). JPG, PNG, WebP, AVIF and HEIC images that your browser can read are all fine, up to 25 MB.
4. Adjust **horizontal position**, **vertical position** and **zoom** if you want a different crop. The site keeps portrait, landscape and square images inside their frames without breaking the layout.
5. Use **Replace photograph** any time, **Remove** to return to the pretty placeholder, and the arrows to move through the next/previous slot.

Photographs are saved privately in the browser you use (IndexedDB). They are never sent to a server. Use the same browser and device for uploading and viewing.

The **Music** tab in the same studio stores one song, played only when Faves presses play.

## Notes

- The 16 memories-gallery captions are placeholders ("A moment worth keeping ♡", etc.). Real memories are never invented; you can replace those captions and add optional dates in `src/config/photos.ts` (`caption` and `date` fields).
- Every placeholder is a beautiful illustrated frame before a photo is added, so the site looks finished on day one.
- Gallery images are lazy-loaded; the welcome and hero portraits load eagerly for a fast first paint.
- The single source of truth for slots is `src/config/photos.ts`; the studio you see in the app is generated from that list.
